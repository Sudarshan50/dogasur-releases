# Dogasur

Public install files for Dogasur. The current build is a **beta**.

Download [Dogasur 2.0 Beta](https://github.com/Sudarshan50/dogasur-releases/releases/tag/v2.0.0). The older 1.0 release is still listed as Latest because GitHub keeps that label off a beta.

## Android

1. Download `Dogasur.apk` from the beta release.
2. Open the file on the phone.
3. If Android asks, allow installation from your browser or Files app.

## iPhone

Install `Dogasur.ipa` with [Sideloadly](https://sideloadly.io). A Mac is the simpler path. Windows works too.

You need a cable, the iPhone unlocked, and an Apple ID. A free Apple ID is enough. An app signed with a free Apple ID stops opening after 7 days. Plug the phone into the same computer and install it again, or leave Sideloadly’s automatic refresh turned on.

After Sideloadly finishes, turn on **Developer Mode** on the iPhone and trust your Apple ID. The app will not open until both are done. Those steps are the same on Mac and Windows, and they are listed under **On the iPhone** below.

### Mac

1. Download Sideloadly for macOS from [sideloadly.io](https://sideloadly.io).
2. Open it. If macOS says the app cannot be opened, go to **System Settings → Privacy & Security** and choose **Open Anyway**.
3. Download `Dogasur.ipa` from the [beta release](https://github.com/Sudarshan50/dogasur-releases/releases/tag/v2.0.0).
4. Plug the iPhone into the Mac. Unlock the phone and tap **Trust This Computer**.
5. In Sideloadly, choose the iPhone. Drag `Dogasur.ipa` into the window.
6. Enter your Apple ID. If Apple sends a verification code, type it in.
7. Click **Start** and wait until Sideloadly says the install finished.
8. Continue with **On the iPhone** below. Leave the phone plugged in until Developer Mode is on.

### Windows

1. If iTunes or iCloud came from the Microsoft Store, uninstall those copies.
2. Install the desktop versions of [iTunes](https://www.apple.com/itunes/) and [iCloud](https://www.apple.com/icloud/download/) from Apple’s website. Sideloadly needs those, not the Store apps.
3. Download Sideloadly for Windows from [sideloadly.io](https://sideloadly.io) and install it.
4. Download `Dogasur.ipa` from the [beta release](https://github.com/Sudarshan50/dogasur-releases/releases/tag/v2.0.0).
5. Plug the iPhone in, unlock it, and tap **Trust This Computer**.
6. Open Sideloadly, choose the iPhone, and drag `Dogasur.ipa` into the window.
7. Enter your Apple ID and any verification code Apple sends.
8. Click **Start** and wait until the install finishes.
9. Continue with **On the iPhone** below.

### On the iPhone

Do this after Sideloadly has finished installing Dogasur. Developer Mode only shows up once that install is on the phone.

1. Open **Settings → Privacy & Security**.
2. Scroll to the bottom and tap **Developer Mode**.
3. Turn **Developer Mode** on.
4. Tap **Restart** when the iPhone asks.
5. After the phone turns back on, unlock it. Tap **Turn On**, then enter the passcode.
6. Open **Settings → General → VPN & Device Management**.
7. Tap your Apple ID, then tap **Trust**.

Dogasur is on the Home Screen. Open it from there.

If **Developer Mode** is missing from Privacy & Security, confirm Sideloadly finished without an error, then force-quit Settings and open it again.
