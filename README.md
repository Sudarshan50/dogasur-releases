# Dogasur

Public install files for Dogasur. The app source is kept in a private repository.

Download the current version from [Releases](https://github.com/Sudarshan50/dogasur-releases/releases).

## Android

Download `Dogasur.apk` and open it on the phone. Android will ask you to allow installation from your browser or files app.

## iPhone

`Dogasur.ipa` is a Release build signed for a registered device. It is not an App Store download. Install it from a Mac with Apple Configurator or Xcode while that iPhone is connected.
